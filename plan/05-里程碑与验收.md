## 五、固定收尾流程（每个里程碑）

```
1. DoD 逐项实跑并贴证据（不是"我记得跑过"）
2. 布局门 + 脱敏门 + 全量 pytest（本机 3.12）
3. 回写三处状态副本（plan/00 里程碑表、plan/00 台账、plan/05 状态表、README 状态表）
4. 写 plan/HANDOFF-M<next>.md（七节：进度+证据 / 当前事实·状态不变量 / 待办 / 既定口径 K / 环境坑 / DoD / 命令速查）
5. commit（一棒一笔或按逻辑分批，消息写清"做了什么 + 证据在哪"）
6. 有远端则 push 并等 CI 绿；无远端写"本地等价校验"
```

**顺序不得交换**：先验证再回写再交单。状态回写与 HANDOFF 必须在**同一笔提交**里，否则中间态布局门是红的。
