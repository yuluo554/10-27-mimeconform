## 三、生成器设计（`mimeconform/devtools/gen_golden.py`）

**结构**：每个 case 是一个纯函数，返回 `(files: dict[str, bytes], expect: dict)`。生成器只做拼装，**不解析、不判定**——期望缺陷由**手写常量 + 构造时的结构性断言**给出（不是"跑一遍工具看输出"）。这是为了避免"真值 = 被测实现的输出"这种自证循环。

```python
def build(out_dir: Path) -> None:
    cases = [b_no_boundary, b_boundary_long, ..., c_clean_mbox]
    for case in cases:
        files, expect = case()
        _self_check(case.__name__, files, expect)   # ← 挂在 build() 里，不是 __main__
        _write_case(out_dir / case.__name__, files, expect)
```

**纪律**：

1. **不得读时钟、不得用 `random` 无种子**：拼装只依赖字面量；需要重复块时用确定性循环。
2. **`_self_check()` 挂在 `build()` 末尾**（skill 第十九形态）：断言"每个正例 case 的 `expect.defects` 非空"、"每个负例 case 的 `expect.defects == []`"、"`expect` 里每条 `rfc` 非空"、"正例 case 的文件确实含它声称的字节"（如 `t-qp-artifact` 的 `msg.eml` 必须真含 `=ustomers`）。
3. **`--check` 语义**：重跑 `build()` 到临时目录 → 与 `data/golden/` 逐字节比对 → 输出 `N cases, 0 diff` 或逐项列出差异 → 非零退出。**临时目录在系统临时目录里，不在仓库内**（不污染工作树）。
4. **行尾**：`.eml` / `.mbox` 内部**保留真实 CRLF 或 LF**（两者都是被测形态）；写盘用 `write_bytes()`，不用文本模式（避免 Windows 自动 `\r\n`）。`.gitattributes` 已对 `data/golden/**` 设 `-text`。
5. **合成白名单**（`data/README.md` §六）：域名 `example.invalid`、地址 `alice@example.invalid` / `bob@example.invalid`、`Message-ID` 用 `<fixed-NNNN@example.invalid>`、附件名只用 `a.txt` / `报告.pdf` / `naïve.png` / `img001.png` 这类假名。**校验器**：`_self_check` 里断言"文件里不得出现 `.com` / `.net` / `.org` 域"（`example.invalid` 之外）。
6. **规模诚实**：每 case 是**小型定向样本**（10–60 行），不是语料库；README 不得写"大规模验证"。

## 四、`expect.json` 契约

```json
{
  "case": "b-inner-dup",
  "source": "cpython #69914",
  "input": {"file": "msg.eml", "sha256": "<hex>", "bytes": 512},
  "exit_code": 3,
  "defect_count": 1,
  "defects": [
    {
      "rule_id": "MC-B06",
      "class": "hard",
      "severity": "major",
      "path": "0.1",
      "offset": 106,
      "offset_kind": "absolute",
      "rfc": "RFC 2046 §5.1.1",
      "detail": "nested multipart reuses outer boundary 'X'"
    }
  ],
  "expect_extra": {
    "tree_alternatives": 2,
    "divergence_path": "0.1"
  },
  "fingerprint": "<sha256>",
  "tree_digest": "<sha256>",
  "stdlib_compare": {"defects": 0, "note": "标准库未报缺陷（#69914 的形状）"}
}
```

**比对纪律（评分口径）**：比对键 = `rule_id` / `path` / `offset` / `class`（**不比 `severity`** —— 受原句门禁影响会随里程碑提升，`plan/01` §四）。

- `defects` **顺序无关**（比对前按 `(rule_id, path, offset)` 排序）。
- `defect_count` 必须等于 `len(defects)`；`exit_code` 必须等于 `decide_exit_code(defects, fail_on="major")`（**由构造算出，不手写魔数**）。
- `fingerprint` / `tree_digest` 由生成器用**与 `ledger.py` 相同的算法**算出——这两处实现必须逐字节一致，`tests/test_fingerprint_parity.py` 用同一组输入双实现比对。
